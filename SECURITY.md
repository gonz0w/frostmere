# Security and privacy

Frostmere is an early local single-player game. No supported release or response
SLA is promised yet. Reports about current source are welcome.

Do not post secrets, private player data or exploit-bearing attachments in public
issues. For a sensitive vulnerability, use GitHub's private vulnerability reporting
on this repository's Security tab if available. If it is unavailable, open a
minimal issue asking the owner for a private channel without disclosure details.
Ordinary crashes and gameplay bugs belong in public issues with sanitized logs.

Run code and contributed assets only from sources you trust. Keep backups before
trying development builds. Save validation and recovery limits are documented in
[SAVE_RESUME.md](docs/SAVE_RESUME.md). Release qualification will establish the
supported-version and reporting policy before a supported release.
