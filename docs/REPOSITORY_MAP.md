# Repository map

`project.godot` selects `scenes/main.tscn`. `scripts/world.gd` assembles the world,
controllers, player and HUD. `scripts/blocks.gd` batches generated cuboid geometry;
shaders provide water/sky presentation. Source-generated assets preserve the
block-built art direction without one scene node per environment cube.

A saved-item change flows from `data/characters.json` and `data/crafting.json`
through `scripts/character_state.gd`, `scripts/skill_rules.gd` and workshop/trade
controllers to character visuals and menus. Check `tests/characters.gd`,
`tests/crafting.gd` and `tests/session_save.gd` when those contracts change.

Player input/combat lives in `scripts/player.gd`; enemy/projectile and regional
controllers implement encounters. `data/world_atlas.json` describes the atlas;
chapter controllers own actual progression. The [campaign review matrix](CAMPAIGN_REVIEW.md)
maps atlas entries, branch fixtures and the human review procedure. Stable IDs connect loot, quests and
saves. Inspect the chapter guide and matching fixture before editing those IDs.

- `scripts/`, `scenes/`, `shaders/`, `data/`: maintained runtime source.
- `assets/audio/`: committed original audio, generated by `tools/build_*audio.py`.
- `tests/`: headless behavior fixtures and native review captures. Render tests
  are not interchangeable with behavior tests.
- `tools/`: profiling, audit, capture-gallery and packaging helpers.
- `docs/`: product guides and explicitly historical development evidence.
- `.agent-temper/`: immutable method bundle; PROJECT.md selects applicable rules.
- `.godot/`, `.tools/`, `build/`, `dist/`: local generated/external artifacts,
  excluded from source distribution. Historical links into build require local
  regeneration; they are not downloadable release promises.

[CONTRIBUTING.md](../CONTRIBUTING.md) owns checks. [GitHub Issues](https://github.com/gonz0w/frostmere/issues)
own all live work. The repository retains the historical Godot application name
to preserve existing user-data locations; the public title is Frostmere.
